# CAMPUSCARE
## Campus Complaint Management System

### About the Project
CampusCare is a Python Tkinter-based desktop application developed to simplify campus complaint management.

It allows students to submit complaints regarding campus facilities and enables administrators to review, manage and resolve them.

### Technologies Used
- Python
- Tkinter
- JSON
- CSV
- Hashlib
- DateTime

### Features
1. Student Registration
2. Student Login
3. Admin Login
4. Complaint Submission
5. Complaint Tracking
6. Admin Dashboard
7. Complaint Status Updates
8. Complaint Details View
9. CSV Export
10. Local JSON Data Storage

### Complaint Categories
- Classroom
- Hostel
- Library
- Canteen
- Cleanliness
- Water Supply
- Electricity
- Wi-Fi / Internet
- Transport
- Washroom
- Other

### How to Run the Project

1. Install Python on your computer.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Execute the following command:

```bash
python "CAMPUS COMPLAINT MANAGEMENT.py"
```

### Data Storage
The application uses JSON files to store student accounts and complaint records locally.

- students.json
- complaints.json

### Project Objective
To provide a simple, organized and transparent platform for students to report campus problems and track their resolution.
